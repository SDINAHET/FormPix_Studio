# FormPix Studio Privacy Policy

Last updated: August 9, 2026

FormPix Studio does not collect, sell, transmit, or share personal data. Images are processed locally in the user's browser and are not uploaded to the developer or any third-party server.

FormPix Studio stores only interface preferences in Chrome local storage. When a user explicitly asks to import an image from a webpage, Chrome requests optional access to that image's website. This access is used only to retrieve the selected image for local processing.

The user may instead choose optional access to all HTTP and HTTPS websites. Chrome requests this permission once. FormPix Studio still uses it only after an explicit image context-menu action, solely to retrieve that selected image. The user can switch back to per-site access or remove website permissions in Chrome at any time.

The optional export history stores only the output filename, source label, date, format, dimensions, file size and Chrome's local download identifier in the user's local Chrome profile. The identifier lets a deliberate click ask Chrome to open the downloaded file in the operating system's default image viewer. It never stores image pixels and can be disabled or erased at any time.

FormPix Studio contains no advertising, analytics, tracking, remote code, or user accounts. Unlike some comparable extensions, there is no anonymous-usage setting because FormPix Studio does not transmit usage statistics at all.
